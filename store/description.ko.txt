🗑️ 몇 초 만에 Gemini 대화를 일괄 삭제하세요. 전체 선택 또는 개별 선택 후 한 번의 클릭으로 삭제합니다.

Gemini 대화를 하나씩 삭제하는 게 지겨우신가요? Gemini Chat Cleaner는 Gemini 사이드바에 선택 모드를 추가하여 여러 대화를 한 번에 표시하고 모두 삭제할 수 있게 해드립니다. 채팅 기록을 빠르게 정리하기에 완벽합니다.

사용 방법
—————————

1. gemini.google.com 열기
2. 화면 오른쪽 가장자리의 탭 클릭 – 또는 Ctrl+Shift+X (Mac은 ⌘⇧X) 누르기
3. 대화를 클릭하여 선택하거나 선택 해제
4. Enter 누르기 (확인 → 다시 Enter) 또는 삭제 클릭

⌨️ 키보드 단축키
——————————————————

• Ctrl+Shift+X / ⌘⇧X — 선택 모드 켜기/끄기
• 클릭 — 채팅 선택/선택 해제
• Ctrl+A / ⌘A — 모든 채팅 선택
• Ctrl+D / ⌘D — 선택 초기화
• Enter → Enter — 선택한 항목 삭제 (2단계 확인)
• Escape — 선택 모드 종료

✨ 기능
—————————

✓ 원하는 수만큼 대화 일괄 선택 및 삭제
✓ 단축키 하나로 전체 선택
✓ 2단계 삭제 확인 – 실수로 삭제하는 일 없음
✓ 진행률 표시줄 – 삭제 중 실시간 피드백
✓ 낙관적 UI – 채팅이 즉시 사라지며, 오류 시 복원
✓ 완전한 키보드 기반 워크플로
✓ 가벼움 – 백그라운드 스크립트 없음, 서드파티 서버 통신 없음
✓ 계정 불필요, 로그인 불필요, 데이터 수집 없음

🔒 개인정보 보호
——————————————

Gemini Chat Cleaner는 개인 데이터를 수집, 저장 또는 전송하지 않습니다. 사용자를 대신하여 Gemini 자체 API에 직접 삭제 요청만 보냅니다 — gemini.google.com이 수동으로 채팅을 삭제할 때 수행하는 것과 동일한 요청입니다.

요청 권한:
• gemini.google.com – 사이드바 읽기 및 삭제 API 호출에 필요
