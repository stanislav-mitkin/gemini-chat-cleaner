🗑️ Удаляйте диалоги Gemini массово — за секунды. Выделите все или выберите нужные чаты и удалите одним кликом.

Надоело удалять чаты Gemini по одному? Gemini Chat Cleaner добавляет режим выбора прямо в боковую панель Gemini, чтобы вы могли отметить сразу несколько диалогов и удалить их все одновременно. Идеально, чтобы быстро навести порядок в истории чатов.

КАК ЭТО РАБОТАЕТ
————————————————

1. Откройте gemini.google.com
2. Нажмите кнопку «Выбрать чаты» в правом нижнем углу — или клавиши Ctrl+Shift+X (⌘⇧X на Mac)
3. Кликайте по диалогам, чтобы отмечать или снимать выбор
4. Нажмите Enter (подтверждение → Enter ещё раз) или кнопку «Удалить», чтобы убрать все выбранные

⌨️ ГОРЯЧИЕ КЛАВИШИ
———————————————

• Ctrl+Shift+X / ⌘⇧X — Войти / выйти из режима выбора
• Клик — Выбрать или снять выбор с чата
• Ctrl+A / ⌘A — Выбрать все чаты
• Ctrl+D / ⌘D — Сбросить выделение
• Enter → Enter — Удалить выбранные (подтверждение в два шага)
• Escape — Выйти из режима выбора

🔒 КОНФИДЕНЦИАЛЬНОСТЬ
——————————————————

Gemini Chat Cleaner не собирает, не хранит и не передаёт никакие персональные данные. Расширение лишь отправляет запросы на удаление напрямую в собственный API Gemini от вашего имени — те же самые запросы, которые gemini.google.com выполняет, когда вы удаляете чат вручную.

Запрашиваемые разрешения:
• gemini.google.com — необходимо для чтения боковой панели и вызова API удаления
