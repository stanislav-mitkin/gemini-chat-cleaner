🗑️ 几秒钟内批量删除 Gemini 对话。选择全部或指定聊天，一键删除。

厌倦了逐个删除 Gemini 对话？Gemini Chat Cleaner 在 Gemini 侧边栏中添加选择模式，让你一次选中多个对话并批量删除。快速清理聊天记录的最佳工具。

使用方法
—————————

1. 打开 gemini.google.com
2. 点击屏幕右侧边缘的标签页 – 或按 Ctrl+Shift+X（Mac 上为 ⌘⇧X）
3. 点击对话以选择或取消选择
4. 按 Enter（确认 → 再次按 Enter）或点击删除

⌨️ 键盘快捷键
——————————————————

• Ctrl+Shift+X / ⌘⇧X — 进入 / 退出选择模式
• 点击 — 选择或取消选择聊天
• Ctrl+A / ⌘A — 全选聊天
• Ctrl+D / ⌘D — 清除选择
• Enter → Enter — 删除已选项（两步确认）
• Escape — 退出选择模式

✨ 功能特性

✓ 一键快捷键全选

✓ 进度条 — 删除时实时反馈

🔒 隐私说明
——————————

Gemini Chat Cleaner 不收集、存储或传输任何个人数据。它仅代表你直接向 Gemini 自有 API 发送删除请求 — 与你在 gemini.google.com 手动删除聊天时发送的请求完全相同。

所需权限：
• gemini.google.com — 用于读取侧边栏及调用删除 API
