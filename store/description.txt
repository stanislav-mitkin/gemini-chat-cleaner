🗑️ Bulk-delete Gemini conversations in seconds. Select all or pick chats — then delete with one click.

Tired of deleting Gemini conversations one by one? Gemini Chat Cleaner adds a Select mode to the Gemini sidebar so you can pick multiple conversations and delete them all at once. Perfect for cleaning up your chat history fast.

HOW IT WORKS
————————————

1. Open gemini.google.com
2. Click the "Select chats" button in the bottom-right corner — or press Ctrl+Shift+X (⌘⇧X on Mac)
3. Click any conversation to toggle its selection
4. Press Enter (confirm → Enter again) or click Delete to remove them all

⌨️ KEYBOARD SHORTCUTS
——————————————————

• Ctrl+Shift+X / ⌘⇧X — Enter / Exit Select mode
• Click — Toggle chat selection
• Ctrl+A / ⌘A — Select all chats
• Ctrl+D / ⌘D — Clear selection
• Enter → Enter — Delete selected (two-step confirmation)
• Escape — Exit Select mode

🔒 PRIVACY
———————

Gemini Chat Cleaner does not collect, store, or transmit any personal data. It only sends delete requests directly to Gemini's own API on your behalf — the same requests gemini.google.com itself makes when you delete a chat manually.

Permissions requested:
• gemini.google.com — required to read the sidebar and call the delete API
