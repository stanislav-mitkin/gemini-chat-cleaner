🗑️ 幾秒內批量刪除 Gemini 對話。選擇全部或指定聊天，一鍵刪除。

厭倦了逐一刪除 Gemini 對話嗎？Gemini Chat Cleaner 在 Gemini 側邊欄中新增選擇模式，讓你一次標記多個對話並批量刪除。快速清理聊天記錄的最佳工具。

使用方法
—————————

1. 開啟 gemini.google.com
2. 點擊螢幕右側邊緣的標籤頁 – 或按 Ctrl+Shift+X（Mac 上為 ⌘⇧X）
3. 點擊對話以選取或取消選取
4. 按 Enter（確認 → 再次按 Enter）或點擊刪除

⌨️ 鍵盤快捷鍵
——————————————————

• Ctrl+Shift+X / ⌘⇧X — 進入 / 退出選擇模式
• 點擊 — 選取或取消選取聊天
• Ctrl+A / ⌘A — 全選聊天
• Ctrl+D / ⌘D — 清除選取
• Enter → Enter — 刪除已選項（兩步確認）
• Escape — 退出選擇模式

🔒 隱私說明
——————————

Gemini Chat Cleaner 不收集、儲存或傳輸任何個人資料。它僅代表你直接向 Gemini 自有 API 發送刪除請求 — 與你在 gemini.google.com 手動刪除聊天時發送的請求完全相同。

所需權限：
• gemini.google.com — 用於讀取側邊欄及呼叫刪除 API
