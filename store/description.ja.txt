🗑️ Geminiの会話を数秒でまとめて削除。全選択または個別に選択して、ワンクリックで削除できます。

Geminiの会話を1件ずつ削除するのに疲れましたか？Gemini Chat Cleanerは、Geminiのサイドバーに選択モードを追加し、複数の会話をまとめて選んで一括削除できます。チャット履歴をすばやく整理するのに最適です。

使い方
——————

1. gemini.google.comを開く
2. 画面右端のタブをクリック – またはCtrl+Shift+X（MacはMacは⌘⇧X）を押す
3. 会話をクリックして選択・選択解除
4. Enterキーを押す（確認 → もう一度Enter）または「削除」をクリック

⌨️ キーボードショートカット
——————————————————————

• Ctrl+Shift+X / ⌘⇧X — 選択モードのオン/オフ
• クリック — 会話を選択・選択解除
• Ctrl+A / ⌘A — すべて選択
• Ctrl+D / ⌘D — 選択をクリア
• Enter → Enter — 選択した会話を削除（2ステップ確認）
• Escape — 選択モードを終了

✨ 機能
——————

✓ 任意の数の会話を一括選択・削除
✓ ショートカット1つですべて選択
✓ 2ステップの削除確認 – 誤削除防止
✓ プログレスバー – 削除中のリアルタイムフィードバック
✓ 楽観的UI – 会話は即座に消え、エラー時は復元
✓ 完全キーボード操作対応
✓ 軽量 – バックグラウンドスクリプトなし、サードパーティサーバーへの通信なし
✓ アカウント不要、ログイン不要、データ収集なし

🔒 プライバシー
—————————

Gemini Chat Cleanerは個人データを収集、保存、送信しません。ユーザーに代わってGemini自身のAPIに削除リクエストを直接送信するだけです。これはgemini.google.comが手動でチャットを削除するときに行う操作と同じです。

要求される権限：
• gemini.google.com – サイドバーの読み取りと削除APIの呼び出しに必要
